# Publication Figures & Reproducibility Diagrams

Contains publication-ready figures for the manuscript:
- `MAIN_F1_framework_split`: Framework and frozen split/evaluation protocol.
- `MAIN_F2_site_exposure`: Class-conditioned registrable-site exposure under Regimes A and C.
- `MAIN_F3_A_C_performance`: Primary MCC performance comparison under random vs site-disjoint splits.
- `MAIN_F4_A_minus_C_MCC_gap`: A-to-C MCC contrast with 95% site-cluster percentile bootstrap intervals.
- `MAIN_F5_global_attribution`: Within-model global feature attribution comparison across regimes.
- `MAIN_F6_sensitivity`: Multiplicity cap (Cap-10, Cap-5) and shortener exclusion sensitivity checks.
- `MAIN_F7_error_burden`: False-positive and false-negative burden comparison.

Available in PNG, SVG, and vector PDF formats.
