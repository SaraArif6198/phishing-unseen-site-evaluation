# Source Stream Acquisition Module

Utilities for building the evaluation streams:
- `acquire_phishtank.py`: Downloads/freezes PhishTank online-valid snapshot.
- `freeze_tranco.py` / `freeze_tranco_frame.py`: Constructs persistent 2,500-domain Tranco frame.
- `extract_commoncrawl_checkpointed.py`: Resumable page-level URL extraction from Common Crawl index.
